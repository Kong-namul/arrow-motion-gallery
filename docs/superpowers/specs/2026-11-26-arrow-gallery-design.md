# 좌우 화살표 레퍼런스 갤러리 — 설계

- 날짜: 2026-11-26
- 상태: 사용자 승인 (갤러리 + 스펙 MD, 도감 전용 토큰, 배포 포함)

## 목적

페이지네이션, 페이지 넘기기, 가로 스크롤, 캐러셀에 쓰는 좌우 화살표를 인터넷에서 최대한 많이 모아,
**눈으로 애니메이션 감을 비교**하고 **번호로 지시**할 수 있게 정리한다.
("B-04처럼 만들어줘" 한 줄이면 다른 작업자/Claude가 같은 결과를 낼 수 있어야 한다.)

## 번호 체계

- **S** 모션 세트 매트릭스 (2026-11-26 추가 요청): 모션 세트 4개(`S1`~`S4`) × 버튼 종류(`T01`~`T15`)
- **A** 캐러셀/슬라이더 화살표
- **B** 페이지네이션 화살표
- **C** 호버·클릭 마이크로인터랙션
- **D** 가로 스크롤 (오버플로 화살표, 엣지 페이드, 칩 바, CSS `::scroll-button`)
- **E** 페이지 넘김·뷰어 (리더, 라이트박스, 슬라이드쇼, 달력 월 이동, 커서 화살표)
- **F** 아이콘 글리프 모음 (chevron / caret / arrow / arrow-long / circle 등)
- **G** 버튼 모션 카탈로그 (종류별 개별 효과. 2026-11-26 추가 요청)

번호는 카테고리 내 순번 두 자리(`A-01`). 한 번 붙인 번호는 바꾸지 않는다.

## 모션 세트 매트릭스 (S)

- "세트감" = 한 세트 안의 모든 버튼이 같은 easing 계열, 같은 누름 스케일, 같은 duration 사다리, 같은 넛지 거리, 같은 상태 레이어 투명도를 공유하는 것.
- 세트는 `--m-*` CSS 변수 묶음으로 정의한다. 버튼 종류 CSS는 `--m-*` 변수와 DS 토큰만 참조한다.
  → 세트를 바꾸면 변수만 바뀌고 모든 버튼이 같은 모션 언어로 바뀐다.
- 화면: 행 = 버튼 종류, 열 = 세트. 데스크톱은 4열 나란히, 모바일은 세트 탭으로 1열.
- 아래에 세트별 변수 비교표 + 근거(디자인 시스템 모션 토큰 출처).
- "세트 CSS 복사" = 변수 블록 + 전 종류 CSS + 마크업 + 동작 JS.
- 세트 값은 리서치(Material 3, Carbon, Fluent, Apple 스프링, Emil Kowalski 등)에서 도출하고 출처를 붙인다.
- 버튼 종류: 프라이머리, 세컨더리, 고스트, 아이콘, 화살표 페어, CTA+화살표, 로딩→성공, 홀드 확인(위험), 토글/좋아요, 복사, 세그먼트, 스위치, FAB 메뉴, 드롭다운, 페이지네이션 줄.

## 카드 구성

1. 번호 + 이름
2. 라이브 데모 (호버/클릭/스크롤로 실제 동작)
3. 모션 수치: 트리거 → 속성 변화, duration(ms), easing. 출처에 수치가 없으면 `추정` 표시
4. 느낌 태그 (예: 빠릿, 차분, 장난스러움, 프리미엄)
5. 어울리는 용도
6. 출처 링크
7. CSS 복사 버튼 (데모에 실제로 적용된 CSS 문자열 그대로)

## 동작 규칙

- **CSS 단일 출처:** 각 항목의 CSS 문자열을 런타임에 `<style>`로 주입한다. 복사되는 CSS = 화면에 보이는 CSS.
- **슬로모션(0.25x):** CSS를 건드리지 않고 `transitionrun`/`animationstart` 이벤트에서 Web Animations API `playbackRate`를 바꾼다. 복사되는 CSS에 배속 변수가 섞이지 않는다.
- `prefers-reduced-motion: reduce`면 루프 애니메이션은 멈추고, 상태 변화만 즉시 보인다.
- 모든 화살표 버튼에 `aria-label`, 키보드 포커스 링.

## 스타일 규칙 (전역 CLAUDE.md 준수)

- 색·폰트·간격·라운드·그림자·모션은 DS 토큰만 쓴다. 하드코딩 금지.
- 타이틀은 단색(라이트=블랙, 다크=화이트). 보라 액센트는 쓰지 않는다.
- 데모 화살표도 흑백/그레이 단색. 원본 라이브러리 고유색은 스펙에 수치로만 기록.
- 폰트 크기는 DS 스케일(72/48/32/24/22/18/16/14)에서만 고른다.
- 공통 CSS/JS 수정 시 `?v=` 버전을 올린다.
